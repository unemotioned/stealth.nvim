*stealth.txt*   Stealth theme for Neovim inspired by Monkeytype Stealth

==============================================================================
STEALTH.NVIM                                                   *stealth.nvim*

Stealth is a dark, ultra-minimalist, high-contrast colorscheme for Neovim
designed with the aesthetic of Monkeytype's iconic "Stealth" theme.

It features personalized syntax highlights for comments, keywords, functions,
variables, strings, and types, along with highlight support for Treesitter, LSP,
Semantic Tokens, Telescope, Neo-Tree, NvimTree, Gitsigns, Cmp, Blink, Lualine,
WhichKey, and many more plugins.

==============================================================================
USAGE                                                          *stealth-usage*

To load the default Stealth theme:

    >vim
    colorscheme stealth
    <

Call setup() first when passing custom options:

    >lua
    require('stealth').setup()
    vim.cmd.colorscheme('stealth')
    <

Or in your Neovim configuration plugin spec (Lazy.nvim):

    >lua
    {
      "LucFerrei/stealth.nvim",
      lazy = false,
      priority = 1000,
      opts = {},
      config = function(_, opts)
        require("stealth").setup(opts)
        vim.cmd.colorscheme("stealth")
      end,
    }
    <

==============================================================================
CONFIGURATION                                             *stealth-config*

Stealth supports detailed customization options passed into `setup()`:

    >lua
    require('stealth').setup({
      -- Enable transparent background
      transparent = false,

      -- Dim inactive windows
      dim_inactive = false,

      -- Set terminal colors (vim.g.terminal_color_*)
      terminal_colors = true,

      -- Personalized font styles for syntax tokens
      styles = {
        comments = { italic = true },
        keywords = { bold = true, italic = false },
        functions = { bold = false, italic = false },
        variables = { italic = false },
        parameters = { italic = true },
        strings = { italic = false },
        constants = { bold = true },
        types = { bold = false },
        sidebars = "auto", -- "auto", "dark", "transparent", "normal"
        floats = "auto",   -- "auto", "dark", "transparent", "normal"
      },

      -- Omit selected Stealth integration highlights
      plugins = {
        telescope = true, nvimtree = true, neotree = true, oil = true,
        whichkey = true,
        gitsigns = true, cmp = true, blink = true, indent_blankline = true,
        mini = true, trouble = true, dashboard = true, alpha = true,
        noice = true, notify = true, treesitter = true, lsp = true,
        semantic_tokens = true,
      },

      -- Custom color hook
      on_colors = function(colors)
        colors.comment = "#8996a8"
      end,

      -- Custom highlight hook
      on_highlights = function(highlights, colors)
        highlights.Comment = { fg = colors.comment, italic = true }
      end,
    })
    <

The monochrome palette uses orange literals, yellow warnings and TODOs, and
red errors. The former variant option no longer selects a palette and can be
removed from existing configurations.

The "auto" sidebar and float styles follow the global transparent option.
The "normal" style uses the editor background; "dark" and "transparent"
explicitly select an opaque or transparent window background. Completion
menus, selections, and colored title labels retain their backgrounds.
Use colors.bg_base and colors.bg_dark_base in on_colors to customize the
solid inverse text and terminal black colors while transparency is enabled.
Disabling an integration omits Stealth's definitions, not the plugin's own
defaults. LSP, semantic token, and Treesitter flags are independent. The
on_highlights hook runs after integration filtering.
